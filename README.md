# ✈️ Viajá Seguro — Cotizador de Seguros de Viaje

> Aplicación web interactiva desarrollada como proyecto final del curso de JavaScript. Permite a los usuarios calcular y cotizar en tiempo real el costo de un seguro de viaje según el destino, la duración y la cantidad de pasajeros.

## ✨ Características Principales

* **Cálculo Dinámico:** Cotización en tiempo real basada en datos ingresados por el usuario.
* **Manipulación del DOM:** Generación de resúmenes e interfaz adaptativa mediante eventos en JS.
* **Persistencia de Datos:** Almacenamiento local (LocalStorage) para guardar o recuperar cotizaciones previas.
* **Validación de Formularios:** Control de campos obligatorios y manejo de errores de entrada.

---

## 🛠️ Tecnologías Utilizadas

* **Lógica & Funcionalidad:** JavaScript (ES6+)
* **Estructura & Maquetación:** HTML5, CSS3
* **Hosting:** Netlify
